# MonEngine player

Live at **https://myrgic.com/monengine/**. Install it from the browser menu ("Install app" / "Add to Home Screen").

An installable web player for MonEngine packs. It contains **no game data**: you load a `.mon` pack you built from
your own copy of the game, and the pack and your saves stay on your device.

This repository holds only the built site. Built from engine commit `a594027`.
